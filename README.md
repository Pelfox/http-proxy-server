# HTTP прокси

Данный учебный проект реализует сервер с поддержкой HTTP проксирования, улучшая
производительность сети, ускоряя загрузку ресурсов (TTFB) и фильтрацию трафика
по URL.

## Возможности

- **Проксирование** - приём и обработка HTTP-запросов, перенаправление на
  целевой сервер;
- **Кэширование** - хранение ответов с настраиваемым TTL и ограничением по
  размеру;
- **Фильтрация** - блокировка запросов по чёрному списку URL;
- **Логирование** - запись событий с уровнями важности.

## Требования

- CMake `>= 3.20`;
- Компилятор с поддержкой `C++23`.

## Запуск проекта

0. Сделайте локальный клон проекта с GitHub:

```bash
git clone https://github.com/Pelfox/http-proxy-server.git
cd http-proxy-server
```

1. Соберите проект:

```bash
make
```

2. Запустите сервер:

```bash
./build/http-proxy-server
```
